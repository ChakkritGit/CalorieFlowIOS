# เลเยอร์ไอคอนสำหรับ Icon Composer

เอาไปประกอบเป็นไอคอนแบบ Liquid Glass ใน Icon Composer ซึ่งอยู่ที่
`/Applications/Xcode-beta.app/Contents/Applications/Icon Composer.app`
(หรือเปิดจาก Xcode → Open Developer Tool → Icon Composer)

ทุกไฟล์ขนาด 1024×1024 เท่ากัน วางทับกันตรง ๆ ได้เลยโดยไม่ต้องขยับหรือย่อขยาย

| ไฟล์ | เป็นอะไร | หมายเหตุ |
| --- | --- | --- |
| `1-background.png` | พื้นหลังไล่สีเขียว เต็มกรอบ | ใส่เป็น Background — หรือจะสร้างไล่สีใน Icon Composer เองก็ได้ จะได้ความลึกที่ดีกว่า |
| `2-ring-track.png` | รางวงแหวน ขาวจาง 22% | พื้นหลังโปร่ง |
| `3-ring-progress.png` | วงแหวนความคืบหน้า ขาวทึบ | พื้นหลังโปร่ง — ชั้นนี้ควรอยู่เหนือรางเสมอ |
| `4-fork-knife.png` | ช้อนส้อมตรงกลาง | พื้นหลังโปร่ง ชั้นบนสุด |

เรียงจากล่างขึ้นบนตามเลขหน้าไฟล์

## ข้อควรรู้

- Icon Composer ใส่แสงสะท้อนและความลึกให้เอง **อย่าวาดเงาหรือไฮไลต์ลงในเลเยอร์**
  ไม่งั้นจะซ้อนกับที่ระบบใส่ให้
- เลเยอร์หน้าควรเป็นสีทึบเรียบ ไม่ต้องไล่สี ระบบจะจัดการเรื่องแสงเอง
- ไฟล์ที่ได้จาก Icon Composer เป็น `AppIcon.icon` เอาไปวางที่รากโปรเจกต์ แล้วตั้ง
  `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` ซึ่งตั้งไว้อยู่แล้ว
- ระหว่างที่ยังไม่มี `.icon` แอปใช้ไอคอนแบน ๆ ใน `Assets.xcassets/AppIcon.appiconset`
  ซึ่งมีตัวแปรมืดกับ tinted ครบแล้ว

สคริปต์ที่เรนเดอร์ไฟล์พวกนี้อยู่ที่ `docs/icon-layers/render.swift`
